# Component Naming Standard

Use immutable IDs in the form `HW-[CATEGORY]-[NUMBER]`, for example `HW-GANESHA-001`. Names may improve; IDs must not be recycled. Asset filenames use the lowercase ID, version and variant: `hw-ganesha-001-v1-mobile.webp`.

Retire superseded records rather than deleting them. A rejected or retired version remains in audit metadata but must never be selectable.
