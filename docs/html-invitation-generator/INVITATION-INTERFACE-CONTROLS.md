# Enveloped invitation interface controls

**Status: Owner-approved (visual and functional review completed
2026-09-25).** The checkpoint was approved as implemented on
`experiment/ivory-palace-frame-journey`, reviewed against baseline
`93a096a`. First used in the Ivory Palace experiment
(`experiments/ivory-palace-frame-journey/`). The visual reference is the
Owner-approved final-frame mockup, used only as a placement and styling
reference; it is not imported.

## Reusable components

The components live in `components/controls.js` as plain JS with no
framework. Their appearance comes from theme tokens (`.theme-ivory-palace`
in `styles.css`); their behaviour lives in the components.

| Component | Role |
|---|---|
| `InvitationUtilityControls` | Music, Gallery and Share (interface layer, upper right) |
| `JourneyNavigationControls` | Previous above Next (interface layer, middle right); endpoint buttons stay visible but disabled |
| `EventCountdownStrip` | Per event: name, live countdown, Location and Calendar (Layer 4, stop 300 only) |
| `LocationAction` | Per event: opens a verified map URL safely |
| `CalendarAction` | Per event: a menu with Google Calendar and a downloadable `.ics` |

- **Pure logic:** `components/event-core.js` handles time zones,
  countdowns, calendar links, `.ics` and URL checks. It is shared with the
  Node tests.
- **Icons:** `components/icons.js` holds inline SVG generated by
  `tools/build-icons.mjs` from the project's existing icon system,
  lucide-react (ISC). No new dependency and no raster images.

## Configuration (`invitation-config.js`)

| Field | Meaning | Default |
|---|---|---|
| `invitationId` | Scopes the session music preference | `ivory-palace-sample` |
| `theme` | Theme class | `ivory-palace` |
| `music.src` | Verified audio URL | `null`, so Music is disabled |
| `gallery.url` | An https view-only album, or a same-origin route such as `/gallery/…` | `null`, so Gallery is disabled |
| `gallery.allowedHosts` | Optional host allowlist | `null` |
| `share.enabled`, `share.title`, `share.text` | Sharing on/off and the shared message | enabled, Ivory Palace text |
| `share.url` | Explicit canonical URL to share | `null`, meaning the current page |
| `share.preservePersonalizedUrl` | Whether the guest's query/hash token is kept in the shared link | `false` |
| `events[]` | `InvitationEvent`: `id`, `title`, `startsAt`, `endsAt`, `timeZone`, `venueName`, `venueAddress`, `description`, `mapsUrl`, `calendar.{googleUrl,icsUrl}` | Haldi and Wedding, `Indian/Mauritius`, **every value null** |

Production defaults invent nothing. With no dates, the strips read "Date
to be announced", and Location and Calendar are disabled.

`?demo=controls` is for review only. It fills the events with relative
future times and the repository's fictional sample venue, and marks the
config `demo: true`. It never adds audio or a gallery. Tests can set
`window.__INVITATION_CONFIG_OVERRIDE`.

## Behaviour

- **Music:**
  - starts muted, and plays only after a click on the Music button;
  - the "on" preference is remembered in `sessionStorage` for the
    session, and after a reload it resumes only on the next user gesture,
    never by autoplay;
  - the icon (`music` / `volume-2`), `aria-pressed` and the label
    ("Play music" / "Pause music") all update;
  - it is disabled ("Music unavailable") while no asset is configured.
- **Gallery:** opens external https destinations with
  `window.open(url, "_blank", "noopener,noreferrer")`, and navigates to
  same-origin routes. Anything unverified (http, `javascript:`,
  protocol-relative, or not on the allowlist) leaves it disabled. There
  are no Drive credentials and no uploads.
- **Share:**
  - uses the Web Share API with the configured title and message;
  - falls back to the clipboard, then to `execCommand("copy")`;
  - `review` and `demo` flags are always removed, and the guest token is
    kept only when `preservePersonalizedUrl` is true;
  - feedback appears in a `role="status"` bubble: "Invitation shared",
    "Link copied" or an error. There are no alerts, and a cancelled share
    stays silent.
- **Navigation:** at rest, both buttons are shown. Previous is disabled
  at 80, and Next is disabled but visible at 300. While travelling, both
  are hidden. Ids, directions, input locking and journey timing are
  unchanged.
- **Countdown:**
  - computed each second from the absolute start instant
    (`toInstant`), converting wall-clock times in the event's IANA zone;
    nothing is decremented from stored numbers;
  - re-syncs on `visibilitychange` after a tab is suspended;
  - never negative;
  - shows "Celebrating now" once the event begins, and "Date to be
    announced" without a date;
  - uses tabular numerals;
  - ticks only while stop 300 is shown, and its timers stop when leaving
    (`destroy()` removes its listeners);
  - the digits are `aria-hidden`, and each strip has a static
    screen-reader description ("Haldi begins Saturday, 22 August 2026 at
    6:30 pm (Indian/Mauritius time).").
- **Location:** each event has its own button, which opens only verified
  https map hosts, with an accessible name such as "Open Haldi location
  in Maps". It is disabled without a valid URL.
- **Calendar:** each event has its own menu, labelled for its event,
  offering Google Calendar (a link opened with `noopener noreferrer`)
  and an Apple/Outlook `.ics` download.
  - The `.ics` follows RFC 5545: UTC times, escaping and 75-octet
    folding. Missing end, venue or description values are omitted, never
    invented.
  - Keyboard: ArrowUp/ArrowDown, Home/End, Escape (focus returns to the
    button) and Tab. A click outside dismisses it. It opens above the
    strip and flips or aligns to stay inside the invitation.
  - It is disabled without a start date.

## Placement (Ivory Palace)

- **Utilities:** `top: max(1.6cqh, 10px)`, `right: max(8px, 3.5cqw − 4px)`,
  in a row with a gap of `clamp(6px, 1.4cqw, 14px)`. The buttons are
  `clamp(44px, 8cqw, 60px)`.
- **Navigation:** the same right inset, `top: 47%`, in a column; it is
  quieter than the utilities.
- **Event strips:** a Layer 4 component zone at 71.9%, below the lower
  enclosure (which ends at 64.3%). Width is `min(94%, max(76%, 272px))`,
  and each strip is `clamp(46px, 4.3cqh, 72px)` tall. They use the
  compact countdown format (`12D:08H:24M:16S`) on strips narrower than
  330px.
- **Stacking:**
  - interface layer: z-index 6;
  - wording and strips (Layer 4): 3;
  - stop layer: 2.

  The interface layer and wording layer take no input themselves; only
  their controls do.

### Known responsive refinement (accepted, not yet addressed)

On the two smallest phones (320×568 and 360×640), the upper-right
utility row slightly overlaps the gold frame's top-right finial at stops
80, 160 and 240. The measured overlap is about 221px² at 320×568 and
67px² at 360×640; there is none at larger sizes. At those widths there
is no room for three 44px targets between the frame's finials. The
Owner accepted this for this checkpoint. It is recorded here and must be
resolved deliberately as a responsive refinement, not silently
redesigned during the next design phase.

### Production configuration still required

All of these live in `invitation-config.js`. Until they are supplied,
the related controls correctly stay disabled or show "to be announced".

- `music.src`: a verified, licensed audio file. Music stays disabled
  until then.
- `gallery.url`: a verified https view-only album (optionally with
  `allowedHosts`) or an application route. There are no Drive
  credentials and no uploads.
- `share.url` / `share.preservePersonalizedUrl`: the canonical share URL,
  and whether personalized guest links may be shared.
- Per event (Haldi and Wedding):
  - `startsAt` and `endsAt` (wall-clock time in `timeZone`, or an
    absolute ISO time);
  - `venueName` and `venueAddress`;
  - a verified `mapsUrl` (https, on a map host);
  - an optional `description`;
  - optional `calendar.googleUrl` / `calendar.icsUrl`.
- Real client data must replace every fictional sample. `?demo=controls`
  is for review only and is never enabled in production rendering.
