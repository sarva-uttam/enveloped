# Asset Review and Approval

Generation is not approval. Technical QA checks file integrity; visual QA checks composition and physical coherence; cultural review checks respectful and accurate use; licence review verifies production rights. Sacred imagery and unfamiliar regional combinations require a competent human reviewer.

Use the lifecycle `PLANNED → GENERATED → UNDER_REVIEW → APPROVED`, or `REJECTED`. Generation progress separately uses `NOT_STARTED → PROMPT_READY → GENERATED → TECHNICAL_QA → VISUAL_QA → APPROVED`; `SUPERSEDED` retains history.

Rejected files must not remain in selectable manifests. Record reviewer, date and reason. Retirement removes new selection but preserves historical invitation rendering and audit metadata where legally permitted.
