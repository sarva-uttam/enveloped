# Compatibility Guide

Validate a candidate before applying it. Rules in `compatibility-rules.json` are authoritative; the UI should keep incompatible options visible but disabled with the rule's explanation.

Single-choice groups replace their previous active member. The principal sacred header, architecture, animal family and opening experience allow one active selection. Flowers allow three principal families and ambient motion allows three continuous families. Required companions and structural supports must resolve before preview or publication.

Warnings invite review; errors block application. Never bypass a cultural or accessibility error to satisfy a visual preference.
