# Tier and Pricing Model

Fixed templates have one controlled structure and one owner-approved fixed price, with only listed content and palette changes. Custom invitations progress Bronze → Silver → Gold → Platinum. Bronze must always offer an attractive, complete path; sacred imagery, RSVP, music, motion and premium additions are not completion requirements.

Classifications are `INCLUDED`, `ENHANCED`, `PREMIUM` and `BESPOKE`. Only active selections are charged. Replacement removes the prior charge. Bespoke items display “quotation required.” If a base tier plus additions costs more than a higher tier containing the same features, recommend that tier without changing it automatically.

All custom values in `pricing.json` are intentionally `PENDING_OWNER_DECISION`. Existing self-serve USD prices in `src/lib/tiers.ts` remain separate and unchanged.
