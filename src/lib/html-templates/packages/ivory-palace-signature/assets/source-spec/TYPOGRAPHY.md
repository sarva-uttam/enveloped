# Typography

Recommended self-hosted system:

| Role | Face | Licence | Mobile / desktop | Line height |
|---|---|---|---|---|
| Couple names only | Alex Brush Regular | SIL OFL 1.1 | 56–82 / 72–108 px | 0.95–1.05 |
| Display titles | Cormorant Garamond 500/600 | SIL OFL 1.1 | 32–46 / 42–64 px | 1.05–1.15 |
| Body/formal wording | Source Serif 4 Regular/Medium | SIL OFL 1.1 | 17–21 / 18–23 px | 1.45–1.65 |
| Utility/small caps | Manrope 500/600 | SIL OFL 1.1 | 12–15 / 13–16 px | 1.25–1.4 |

Licence status: all recommendations are open-licensed and self-hostable under OFL 1.1. Confirm the exact downloaded release and retain its licence file before bundling. No font is included in this review package and no runtime Google Fonts request is permitted.

Fallbacks:

- Alex Brush → `Segoe Script`, `Brush Script MT`, cursive
- Cormorant Garamond → `Iowan Old Style`, Baskerville, Georgia, serif
- Source Serif 4 → `Source Serif Pro`, Georgia, serif
- Manrope → Inter, `Segoe UI`, Arial, sans-serif

Rules: calligraphy is reserved for names; addresses and paragraphs use Source Serif 4; utility text uses sentence case or restrained tracked caps. Apply `font-display: swap`. English and French Latin coverage is required. French accents must be tested before freeze.
