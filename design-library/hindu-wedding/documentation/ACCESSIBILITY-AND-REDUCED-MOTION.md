# Accessibility and Reduced Motion

Client information remains semantic HTML with keyboard access, visible focus, zoom tolerance and validated contrast. Decorative images use empty alt text in the rendered invite; meaningful selected imagery uses registry alt text. Unavailable cards expose their reason programmatically.

Respect `prefers-reduced-motion` and an explicit user control. Replace loops with static poster frames and openings with their final state or a short fade. Never charge for reduced-motion, readable typography, contrast, captions, keyboard support or other essential access.

Music never autoplays and begins only after an intentional interaction. Controls must remain reachable without obscuring sacred or textual content.
