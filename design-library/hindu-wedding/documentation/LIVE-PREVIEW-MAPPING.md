# Live Preview Mapping

The preview starts as a neutral empty 9:16 canvas with guidance that it is not a final design. Selecting a template first chooses a trusted HTML document package. For every later answer: validate compatibility, replace the active item in its single-choice group, pass the selection only into a slot that package declares, apply approved template parameters, validate text contrast and safe areas, recalculate only active charges, auto-save, and append undo history.

Support preview toggle, desktop side panel, mobile expansion, tier and estimated-total labels, loading and failed-asset fallbacks, reduced motion, current-step reset, confirmed full reset, “Let Enveloped choose,” and an auto-save indicator. Persist drafts across refresh and return visits.

The preview must render the selected trusted document package; it must not create raw HTML, CSS or JavaScript from registry or database values. Logical placement metadata constrains declared slots and option-card previews—it does not authorize a universal free-form layer composer. The legacy `InviteCanvas` is not yet this renderer. Integration must preserve the existing HTML Studio validator, payment, RSVP, token and publication boundaries.
