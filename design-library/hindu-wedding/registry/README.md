# Registry files

- `registry.json` identifies the library and logical canvas.
- `templates.json` registers the eight starting compositions.
- `components.json` is the planned component catalogue.
- `palettes.json`, `typography.json`, `animations.json` and `music.json` register controlled option families.
- `compatibility-rules.json` contains machine-readable composition constraints.
- `survey-mapping.json` maps all 22 survey steps to data and preview behavior.
- `placement-rules.json` defines the 1000 × 1778 logical canvas.
- `pricing.json` deliberately leaves commercial values pending.
- `asset-generation-status.json` separates planning, generation and approval state.
