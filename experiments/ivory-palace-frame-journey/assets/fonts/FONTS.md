|---|---|---|
| `alex-brush-latin-400-normal.woff2` | Alex Brush | Ceremonial script: ceremony titles and personal names |
| `playfair-display-latin-400-normal.woff2` | Playfair Display 400 | Formal serif supporting wording |
| `playfair-display-latin-600-normal.woff2` | Playfair Display 600 | Structured serif date component |

Latin subsets only; the Devanagari mantra falls back to the system Devanagari font.
