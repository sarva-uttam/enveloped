# Visual Slot System

All invitation previews use a resolution-independent 1000 × 1778 reference canvas. `placement-rules.json` defines constraints a trusted HTML document package may adopt for its declared visual slots; it is not a universal authorization to stack arbitrary assets.

Text-safe zones are `invitation-introduction`, `couple-names` and `event-summary`. Decorative layers may frame but never obscure them. Sacred artwork uses `sacred-header`, cannot be cropped and keeps its clear space. Grounded objects use the lower plane; backgrounds alone may cover the canvas.

Mobile scales the whole canvas uniformly. Desktop centers the same 9:16 composition inside a wider interface; it never turns the invite into a full-width landscape layout.
