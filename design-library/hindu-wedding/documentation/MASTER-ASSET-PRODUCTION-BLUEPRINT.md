# Hindu Wedding Registry — Master Asset Production Blueprint

Status: **AUTHORITATIVE PRODUCTION BRIEF**  
Market: **Mauritian Hindu weddings**  
Canvas: **1000 × 1778 (9:16)**

This blueprint prevents generation by guesswork. Registry status, review manifests and recorded Owner approval remain authoritative. Components may appear only in slots declared by reviewed HTML invitation packages; no arbitrary runtime composition is permitted.

## Universal production contract

Every brief states the stable ID, version, exact subject/count, anatomy/construction/species, slot, anchor, crop policy, tier, materials, palette, lighting, support/ground contact, safe area, compatible families, prohibited content, exports, provenance and review state.

Raster art is original sRGB artwork without text, fake script, watermark, signature, accidental symbol, duplicate object, disconnected fragment or generation artefact. Transparent artwork uses genuine clean alpha with no halo. Names, dates, venues and blessings remain semantic HTML.

Required static exports: lossless master PNG, optimised alpha WebP, 540×960 option card, 270×480 thumbnail where needed, detail crop and complete manifest. Background sources target 2160×3840 plus 1080×1920 delivery. Transparent masters are at least twice maximum rendered size. Motion also requires WebM/reviewed Lottie, poster frame, exact static final state and reduced-motion fallback.

Positional kits are independently authored as TOP, BOTTOM, LEFT, RIGHT, TOP_LEFT, TOP_RIGHT, BOTTOM_LEFT and BOTTOM_RIGHT. Never mirror sacred orientation, handedness, anatomy, clothing, directional light or botanical growth. Hanging objects show support; grounded objects show believable contact.

Version rules: v1 is the first candidate, not approval. Corrections create v2+; never overwrite reviewed masters. Child variants use labels such as v1-base, v1-fuller-silver, v1-layered-gold or v1-top-left. States are PLANNED/NOT_STARTED, UNDER_REVIEW/VISUAL_QA, APPROVED/COMPLETE, REJECTED and SUPERSEDED. Only approved production paths are selectable.
