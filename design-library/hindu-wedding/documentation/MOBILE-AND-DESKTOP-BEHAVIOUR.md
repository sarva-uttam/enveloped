# Mobile and Desktop Behaviour

Mobile is the native invitation surface: a full-width 9:16 preview with expandable controls and touch-safe option cards. Scale uniformly, preserve logical coordinates and avoid horizontal scrolling.

Desktop uses a side-by-side survey and centered phone-like 9:16 preview. The wider viewport provides interface space, not permission to stretch or rearrange the invitation into landscape. Both surfaces read the same saved preview state and placement metadata.
